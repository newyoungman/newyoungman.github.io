Bio

I am an Agent Engineer at Meituan, working on LLM agents and their evaluation. My current focus is building benchmarks and evaluation systems for tool-use agents, particularly for supply search and local-life search scenarios. I am also interested in information retrieval and reward modeling for agent trajectories.

Projects

Supply Search Relevance LLM

Built the relevance model for Meituan's agent supply search from scratch: decomposed relevance into attributable dimensions (subject / address / time / objective conditions), constructed a 10k+ hierarchical benchmark with automated production pipelines, and trained with SFT + GRPO (verifiable rewards) on Qwen3.5.

OmniReward — Agent Reward System

A serving system scoring agent trajectories across 50+ dimensions (relevance, hallucination, timeliness, safety, reflection, …) with 30+ parallel scorers; cut wall-clock latency by 46% while improving reward quality, and powered GRPO post-training with +0.4 satisfaction gain.

LLM Prompt Recovery — Kaggle Silver Medal

Recovered prompts behind LLM-rewritten text with an ensemble of retrieval, fine-tuned Phi-2, and Mistral-7B prediction, reaching 66.23% sharpened cosine similarity.
